## 目的
MSX Game Cartridge Adapterを経由して、Y8960カートリッジのFPGA、ファームウェアをアップデートするツールを作成する。

## ターゲット
Windows / Linux

## 仕様
..\Y8960_Cartridge で提供されている y8960upd.com (MSX-DOS用) と同等の機能を持つ
ただし、ROMについては、生の.romファイルを受け付けられるようにする
実カートリッジとのインターフェースは ..\MSXPLAYer_GameAdapter を使用する

## 開発環境
c++ / cmake / vcpkg

## リポジトリ構成
- doc/plan.md 作業計画・進捗を書く。AI向け
- doc/spec.md オリジナルのツールから読み取った仕様をまとめる。AI/開発者向け
- doc/manual.md 詳細なリファレンスマニュアル・使用例を書く。開発者/エンドユーザー向け
- ./README.md このプロジェクトの概要・ビルド手順・ツールの使い方を書く。開発者・エンドユーザー向け
- ./CLAUDE.md このプロジェクト固有の約束事・手順などを書く。AI向け
- src/ ソースコード
- test/ テストスクリプト
- その他、必要なファイルは適切なフォルダ・ファイル名で作成
